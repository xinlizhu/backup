这是环境记录，不是完整锁文件。原环境中的 transformers 5.2.0 超出了 vLLM 0.19.0 声明的 `<5` 范围，因此 `requirements-gpu.txt` 使用 vLLM 的声明约束，不把这组不一致的安装状态作为新环境的强制依赖。

此次备份验证的是 CPU 测试、命令入口和代码结构，没有在新环境重新加载模型执行 GPU 推理。部署前应使用自备模型和样本验证 CUDA、推理后端及输出一致性。
